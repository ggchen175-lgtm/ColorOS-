# 炒鸡美化 v0.4.129（157）

面向 ColorOS 的 LSPosed 美化模块。本版主要调整锁屏和桌面下拉通知中心的卡片材质、顶部滚动边缘和锁屏叠放。

**发布状态**　此页记录 0.4.129 的改动和实测结果。该版本的源码快照及安装包待核验，仓库目前仅有版本说明。

## 本版更新

- 通知主卡与叠放底边共用一套色彩矩阵。卡片轮廓内实时采样背景，卡内柔焦半径为 14dp，深浅色模式各自保留适度衬底。
- 锁屏展开与桌面下拉共用顶部渐隐逻辑。通知可以滚过状态栏背后，系统时间、信号和电量保持清晰。
- 锁屏只有一条通知时显示干净的单卡。两条通知时只露一层底边，默认露出 7dp、两侧各缩进 7dp，圆角随主卡轮廓。

## 测试与兼容性

历史测试包通过了 `assembleDebug` 和 `lintDebug`。在一加 15（PLK110，ColorOS 17）上验证了单条通知、同应用两条、不同应用各一条，以及深浅色模式下的下拉滚动。在原始屏幕设置和临时 960×1720、480 dpi 的测试设置下，锁屏和桌面下拉均可滚到列表末端。其他机型和 ROM 的兼容性仍待验证。

需要 Root 与可用的 LSPosed 环境。通知相关功能勾选「系统界面」，桌面功能勾选「系统桌面」，负一屏功能勾选「负一屏」。桌面左侧下拉进入锁屏样式通知中心需要系统启用分离式通知栏。
